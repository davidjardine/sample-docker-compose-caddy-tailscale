# Sample Webserver with Docker Compose using Caddy and Tailscale

Basic files to set up a webserver running using docker compose with caddy and tailscale. 

This repo was created in support of a blog post I wrote that serves as a simple tutorial on hosting your own services using tailscale and caddy in a docker compose environment.

The only thing to note is that I named the environment files "sample.env" because I know some computers will hide any dot files and this was meant to be friendly for even absolute beginners to navigate. So this is meant to avoid someone downloading the repo and not being able to see the .env file. 

Simply rename the "sample.env" files to ".env" once you have made changes to them (or do it at any point if you know how to view hidden dot files on your system).
